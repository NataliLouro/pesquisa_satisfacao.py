# Pesquisa de Satisfação - TudoWeb Marketing

Este projeto consiste num programa em Python desenvolvido para recolher a opinião dos clientes da empresa **TudoWeb Marketing** relativamente à qualidade do atendimento prestado.

## 📌 Funcionalidades
- Recolha de dados (Nome, Idade e Opinião sobre o atendimento).
- Estrutura de repetição para realizar as entrevistas.
- Validação de entrada para opções de menu (1: Excelente, 2: Bom, 3: Ruim).
- Relatório final com a quantidade de avaliações.

## 🧪 Validação e Testes
O programa foi testado e validado com uma amostra de 10 entrevistados no terminal do VS Code, estando configurado para a versão final com 50 entrevistados.
